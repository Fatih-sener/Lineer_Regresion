# Linear Regression / Lineer Regresyon

## English 🇬🇧

This repository contains a simple and clear implementation of **Linear Regression** using **Python**.  
The project demonstrates how to load a dataset, apply linear regression techniques, and analyze the relationship between variables using commonly used libraries such as **pandas**, **NumPy**, and **matplotlib**.

The main purpose of this project is to help beginners understand the fundamentals of linear regression and how it is implemented step by step in Python.

---

## Türkçe 🇹🇷

Bu repository, **Python** kullanılarak geliştirilmiş **basit ve anlaşılır bir Lineer Regresyon** uygulamasını içermektedir.  
Projede bir veri setinin yüklenmesi, lineer regresyon modelinin uygulanması ve değişkenler arasındaki ilişkinin analiz edilmesi gösterilmektedir. Bu süreçte **pandas**, **NumPy** ve **matplotlib** gibi yaygın kütüphaneler kullanılmıştır.

Bu projenin amacı, lineer regresyonun temel mantığını öğrenmek isteyenler için adım adım ve anlaşılır bir örnek sunmaktır.
